## Следующие гипотезы привлечения клиентов

1. Выбор задачи: общественный транспорт / содержание дорог / ситуационный центр → релевантный продукт и демонстрация.
2. Доказательные кейсы: регион, исходная задача, внедрённые модули, измеренный результат с источником и периодом.
3. Запрос демонстрации с выбранным продуктом и понятным сценарием показа; отправку подключать к согласованному каналу.
4. Считать переходы в продукты и обращения; сравнивать долю обращений, а не только клики. Для Метрики нужен реальный номер счётчика.
