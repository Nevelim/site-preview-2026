# Лендинг ИТС — Форум «ИТС России 2026»

Мобильная одностраничная витрина компании для QR-кода с буклетов.
Форум: 28–29.09.2026, Москва, Azimut Отель (https://2026.itsrussiaforum.ru/).

## Состав

```
its-forum-2026/
├── index.html          — страница (все 5 секций)
├── busvision.html      — страница-презентация bus:vision (iframe + кнопки скачивания HTML)
├── presentation-busvision-desktop.html — самодостаточная презентация для ПК (шрифты/картинки внутри)
├── presentation-busvision-mobile.html  — самодостаточная презентация для телефона
├── styles.css          — стили, фирменная палитра its.dev
├── script.js           — визуальные эффекты (vanilla, без библиотек)
├── assets/
│   ├── logo.png        — логотип ИТС (384×125)
│   └── fonts/          — Gilroy Regular/Medium/Semibold/Bold (woff2, ~108 КБ)
├── qr/
│   ├── generate-qr.js  — генератор QR для печати
│   ├── qr-code.png     — ДЕМО QR (its.dev) — перегенерировать перед печатью!
│   └── qr-code.svg     — вектор для макета буклета
└── docs/design.md      — дизайн-документ
```

Полный вес страницы: ~140 КБ (шрифты + логотип + HTML/CSS/JS). Без фреймворков.

## Производительность

- Все гербы и крупные логотипы пережаты до ретина-размера ×3
  (высота 126px): папка партнёров 2,3 МБ → 436 КБ. Полная страница
  ~640 КБ (было ~2,7 МБ).
- У всех изображений версионный суффикс `?v=2` — после замены файлов
  кэш браузера не мешает (при следующей замене поднять до v=3).
- 22 изображения ниже первого экрана — lazy.
- 404.html (редирект на главную для GitHub Pages) и robots.txt.

## Функции для форума (vCard, календарь, OG)

- **Сохранить контакт** (vCard): кнопки в карточках менеджеров скачивают
  .vcf (`assets/contacts/*.vcf`) — визитка одним тапом попадает в телефон.
- **Форум — в календарь**: кнопка скачивает `assets/events/forum-2026.ics`
  (28–29.09.2026, Azimut Отель).
- **OG-картинка** `assets/og.png` (1200×630, 188 КБ) — превью при пересылке
  ссылки в Telegram/WhatsApp. Генератор — `og.html` (открыть и снять
  скриншот 1200×630). После деплоя заменить в `index.html`
  `og:image` на абсолютный URL — иначе мессенджеры её не подхватят.
- **Иконки вкладки**: favicon.png (64×64) и apple-touch-icon.png (180×180,
  тёмная подложка) — только знак «//», вырезанный из логотипа программно
  (assets/mark.png — исходник знака). Полный логотип остался в шапке.
- **Preload шрифтов** Gilroy Bold/Semibold — быстрый первый экран.
- **Презентация** лежит локально (`assets/presentation-its.pdf`,
  3,4 МБ, скачивается по кнопке с атрибутом download) — не зависит от
  медленного сервера its.dev.
- Бейдж «Форум ИТС России 2026» в шапке кликабелен → 2026.itsrussiaforum.ru.

## Идентификация систем фирменными цветами

Карточки продуктов несут цвет своей системы (снято с сайтов продуктов):
линия-градиент сверху карточки, точка у названия, тонированное свечение
при наведении. Цвет используется только декоративно (текст остаётся
стандартным AA-контрастным):

- Платформа ИТС — #007AFC (фирменный синий its.dev)
- bus:vision — #008774 (тил с bus.vision)
- run:vision — #C26B61 (терракота с run.vision)
- hosta:dev — #1677FF (яркий синий с hosta.dev)
- Навигационная платформа — #8E6CF0 (фиолетовый из палитры its.dev)

## Доступность (по итогам ревью)

- Контрасты WCAG AA: кнопки 5.3:1, ссылки/бейджи на карточках 5.7:1,
  текст светлой темы 16:1/6.2:1/4.6:1.
- :focus-visible — видимый фокус для клавиатурной навигации.
- aria-pressed у переключателя темы, aria-label у кнопок-иконок.
- Мобильная панель быстрых действий (звонок + «Обсудить проект»)
  появляется после прокрутки, только на экранах <640px, с учётом
  safe-area iPhone.

## Светлая и тёмная тема

- Тёмная — фирменная (its.dev), светлая — «дневная» (#F4F6F9, белые
  карточки). Весь интерфейс и эффекты (канвас-сеть, маршрут, свечения)
  перекрашиваются через CSS-переменные.
- По умолчанию тема = системной схеме (prefers-color-scheme);
  выбор кнопкой в шапке сохраняется в localStorage и важнее системы.
- Тема применяется inline-скриптом в <head> до отрисовки — без вспышки
  неправильной схемы. meta theme-color синхронизируется (цвет полосы
  браузера на мобильных).
- Белый логотип в светлой теме инвертируется фильтром `brightness(0)`.
- Контрасты светлой темы проверены по WCAG: текст 16:1, карточки 6.2:1,
  ссылки 5.3:1, мелкий текст 4.6:1 (норма AA — 4.5:1).

## Визуальные эффекты (script.js)

Все эффекты — прогрессивное улучшение: без JS страница полностью
работает, при `prefers-reduced-motion: reduce` анимации отключаются
и контент показывается сразу.

1. **Живая транспортная сеть** — canvas в первом экране: синие узлы-«остановки»
   (размер «дышит»), связи-«дороги» и яркие точки-«машины» с пульсирующими
   ореолами, которые ездят по связям с хвостами. Рисуется только пока герой
   на экране, на мобильных объектов меньше.
2. **Маршрут-разделитель** — SVG-линия с 4 «остановками»: пунктир непрерывно
   «течёт» (SMIL), остановки загораются по очереди, по линии бегут две
   точки-транспорта.
3. **Заголовок героя** — пословное появление из маски со сдвигом фаз.
4. **Параллакс героя** — контент слегка отстаёт от прокрутки.
5. **Появление при прокрутке** — секции, карточки и плитки гербов/партнёров
   въезжают «лесенкой» (IntersectionObserver).
6. **Счётчики цифр + «скан данных»** — 20 / 50+ / 406 000+ набегают,
   по карточке пробегает блик сканирования.
7. **Линия-акцент** вырастает под заголовком каждой секции.
8. **Кнопки** — по главной кнопке пробегает блик при наведении.
9. **Карточки** — свечение за курсором в цвете системы, 3D-наклон,
   стрелка «Подробнее →» шевелится при наведении.
10. **Прогресс-бар прокрутки** — тонкая синяя линия сверху.
11. **Шапка** получает тень и синюю кромку после начала прокрутки.

## Деплой (вы выкладываете сами)

Страница — плоская статика, подойдёт любой вариант:

1. **Любой статический хостинг**: скопировать папку целиком
   (index.html, styles.css, assets/) — и всё.
2. **nginx/Apache**: положить в отдельную директорию (например `/forum2026/`).
3. **Поддомен**: `2026.its.dev` или `forum.its.dev` — корневая директория.

Проверка после выкладки: откройте с телефона через мобильный интернет,
убедитесь, что грузится быстро и ссылки на продукты работают.

## QR-код: что сделать до печати буклетов

1. Определить финальный URL страницы.
2. Перегенерировать QR с этим URL:
   ```
   node qr/generate-qr.js "https://ФИНАЛЬНЫЙ-URL/?utm_source=qr&utm_medium=print&utm_campaign=itsforum2026"
   ```
   UTM-метки позволят в Метрике отделить посетителей по QR от остальных.
3. Взять `qr/qr-code.svg` (или PNG 1024px) в макет буклета.
   Правила печати: минимальный размер 2×2 см, не меньше; не размещать
   QR на тёмном фоне (код сгенерирован тёмным на светлом); не обрезать
   белую «тихую зону» вокруг; уровень коррекции H — до 30% повреждений.
4. **Обязательно**: отсканировать QR с макета (PDF-превью тоже подходит)
   несколькими телефонами до отправки в типографию.

## Яндекс.Метрика

1. Создать счётчик на https://metrika.yandex.ru → получить номер.
2. В `index.html` внизу найти закомментированный блок Метрики,
   снять `<!-- -->`, подставить номер вместо `XXXXXXX`.
3. Целевое действие (опционально): клик по «Обсудить проект» —
   добавить в ссылку onclick-цель или отслеживать как JavaScript-событие.
